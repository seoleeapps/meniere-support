# 전정재활 운동 프로그램

2026-10-03 사용자가 기본 운동 안내·수행 기록, 앱을 통한 실제 시선 안정화 프로그램에 이어 **텍스트 지침 대신 시각 자료와 전용 화면을 사용하는 운동 도구**를 승인했다. 홈의 `운동 프로그램`, 생활 화면의 `전정재활 운동 프로그램`에서 연다. 운동 화면에는 광고를 표시하지 않는다.

좌우·상하 시선 안정화는 눈높이에 고정한 휴대폰의 큰 X를 보며 머리를 움직이는 방식이다. 이동하는 표적이나 복잡한 배경을 사용하지 않는다. 의료진이 확인한 운동을 선택하고 회차당 15·30·60·90·120초, 1~5회 중 정한 값을 직접 선택한다. 기본 처방값이나 자동 강도 증가는 없다. 지지물을 이용한 눈 뜬 균형 운동도 안내하며 눈 감기·좁은 지지면·보행·Epley 동작으로 진행하지 않는다.

## 수행과 저장

- 운동·목 움직임 범위·시간·횟수를 담당 의료진과 확인했다고 저장하고, 현재 발작이 없으며 안전한 환경을 준비했다고 선택한 뒤 시작한다. 진행 중 발작 기록이 있으면 시작할 수 없다.
- 시작 때 `미완료` 기록을 먼저 암호화해 저장한다. 앱 강제 종료를 성공적인 수행으로 해석하지 않는다.
- 운동 선택 화면은 자체 제작 벡터 그림으로 고정된 휴대폰·시선과 좌우 회전·상하 끄덕임을 보여준다. 시범은 멈출 수 있으며 시스템 동작 줄이기와 백그라운드에서는 애니메이션을 중지한다. 그림 속 속도는 운동 처방값이 아니다. 자세·주의점의 상세 설명은 접어서 제공한다.
- 시작·재개·다음 회차 전 3초 준비 시간을 둔다. 준비 시간은 수행 시간에 넣지 않는다.
- 운동 중에는 별도 전체 화면에서 고정된 X와 남은 시간, 회차를 표시한다. 표적의 위치·크기는 회차 내에서 변하지 않으며 움직이는 그림을 함께 보여주지 않는다. 운동 중 화면 자동 꺼짐을 막고 일시정지·휴식에서는 해제한다. 휴식에는 앉아 있는 그림을 보여준다. 운동 중 표적 화면은 스크롤하지 않는다. 작은 화면에서는 표적 크기를 높이에 맞추며 운동 중 하단 메뉴를 숨긴다.
- 회차가 끝나면 타이머가 멈추고 휴식한다. 사용자가 편해졌다고 선택해야 다음 회차가 시작된다. 휴식·일시정지·백그라운드 시간은 수행 시간에서 제외한다.
- 앱을 벗어나면 일시정지하며 복귀해도 자동으로 계속하지 않는다. 강한 어지럼·구역, 목 통증과 낙상 위험에는 중단하고 안전하게 앉도록 안내한다. `중단하고 도움`은 즉시 도움 화면을 열며 기존 수행은 미완료로 보존한다. 돌아온 뒤 자동으로 운동을 재개하지 않는다.
- 완료·중단과 실제 수행 초·완료 회차, 계획 사본, 운동 전후 불편감 0~10 또는 미입력, 메모를 남긴다. 불편감은 본인의 기록이며 치료 효과나 개선 판정을 계산하지 않는다.
- 수행 세부 메모·불편감은 보완할 수 있고 개별 기록을 삭제할 수 있다. 원래 프로그램의 완료 여부와 시간은 사실 기록으로 보존한다.
- 진료 기간 요약, PDF, 원본 CSV와 비밀번호 백업에 운동 기록을 포함한다. 백업 충돌은 기존 기록을 기본으로 유지한다. 기존 형식 1의 기록은 형식 2로 변환할 때 운동 이력을 만들어 넣지 않는다.

## 공식 근거와 검수 범위

[NIDCD의 메니에르병 안내](https://www.nidcd.nih.gov/health/menieres-disease)는 만성적인 균형 문제에 의료진이 전정재활·물리치료를 권할 수 있다고 설명한다. 이를 발작 치료나 모든 사용자에게 같은 운동량을 처방한다는 뜻으로 확대하지 않는다.

[North Bristol NHS의 시선 안정화](https://www.nbt.nhs.uk/our-services/a-z-services/physiotherapy/specialist-physiotherapy-service/therapy-erehab-video-resources/therapy-erehab-vestibular), [Sherwood Forest Hospitals NHS 안내](https://www.sfh-tr.nhs.uk/media/2kxnsa40/pil202512-04-vrmp-vestibular-rehabilitation-management-plan.pdf), [Rotherham NHS의 균형 재활](https://www.therotherhamft.nhs.uk/patients-and-visitors/patient-information/standing-balance-retraining)을 확인했다. 원문의 그림·영상은 복제하지 않고 기본 동작을 새 문구로 설명하며 공식 자료 링크를 제공한다. 앱의 그림·애니메이션·고정 표적·타이머는 자체 구현이다. 카메라·마이크·움직임 센서를 쓰지 않으며 머리의 실제 수행 정확도나 치료 효과를 측정했다고 표시하지 않는다.

공식 일반 안내를 바탕으로 만들었지만 **이 앱의 운동 프로그램은 의료진의 제품 검수를 아직 받지 않았다**. 공개 전 이비인후과·전정재활 담당자의 적용 대상, 목·시각·낙상 위험, 중단 기준, 사용성, 운동량 선택·최대치, 도움 접근을 검수해야 한다. 이는 코드·타이머·백업 검사와 별도의 출시 조건이다.

소프트웨어 의료기기 해당 여부는 면책 문구만으로 확정하지 않는다. [FDA의 기능별 소프트웨어 정책](https://www.fda.gov/medical-devices/digital-health-center-excellence/device-software-functions-including-mobile-medical-applications)을 확인했으며, 기록 도구에서 시각 운동 도구로 확장된 실제 기능과 홍보 문구를 기준으로 출시 국가별 분류를 검토해야 한다.
