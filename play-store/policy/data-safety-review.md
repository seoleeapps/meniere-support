# Data safety 검토 초안

2026-10-03 Android 소스와 [Google Mobile Ads 데이터 공개 자료](https://developers.google.com/admob/android/privacy/play-data-disclosure)를 대조했다. **콘솔에 신고하지 않은 검토 초안**이다. 실제 AAB에서 Google Mobile Ads 25.4.0과 UMP 4.0.0을 확인했다. 최종 동의 설정과 기기 동작은 아직 검증하지 않았다.

| 데이터                                    | 현재 동작                                                  | 신고 판단                                                                                   |
| ----------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 증상·생활·전정재활 기록, 진료 질문과 메모 | SQLCipher로 기기에만 저장. 광고·분석·서버 요청에 넣지 않음 | 앱 개발자의 수집·공유 없음. 기기 내 처리와 사용자 직접 선택하는 내보내기를 구분             |
| PDF·CSV·암호화 백업                       | 사용자가 OS 공유·파일 선택으로 직접 저장하거나 전달        | 암호화되지 않은 PDF·CSV와 암호화 백업을 설명. 임의 자동 전송 없음                           |
| IP 주소와 대략적인 위치                   | Google 광고 SDK에서 처리할 수 있음                         | 대략적인 위치의 수집·공유를 검토. 정밀 위치 권한 없음                                       |
| 광고·기기 식별자                          | Google 광고 SDK의 광고 ID·app set ID 등                    | 기기 또는 기타 ID 수집·공유. Android 설정의 광고 ID 제어와 동의 상태를 고려                 |
| 광고/제품 상호작용                        | 광고 SDK의 요청·노출·상호작용 등                           | 앱 상호작용 수집·공유. 제품의 건강 기록을 포함시키지 않음                                   |
| SDK 성능·진단                             | Google 광고 SDK가 처리하는 성능·진단 정보                  | 진단 및 해당 성능 정보 수집·공유. Firebase/Crashlytics 미사용이 SDK 진단 부재를 뜻하지 않음 |

광고 SDK 목적은 광고, SDK 분석 및 부정 사용 방지다. 전송 데이터는 Google 문서의 TLS 보호를 확인했다. 자체 원격 제품 분석은 없다. SDK에 알려진 자동 수집을 앱의 비개인화 요청만으로 `없음`으로 신고하지 않는다.

`App.tsx`의 배너 요청은 `requestNonPersonalizedAdsOnly: true`이며 키워드·증상·메모·의료 관심사나 위치를 전달하지 않는다. `adapters/ads.ts`는 UMP의 `canRequestAds` 확인 이후 광고를 초기화한다. 동의 오류와 광고 불가 상태에도 기록 기능은 사용할 수 있다. 광고 동의 설정과 실제 거절 동작은 production 후보로 검증해야 한다.

외부 계정 생성은 없고 계정 삭제 웹 양식은 필요하지 않다. 사용자는 앱의 전체 또는 개별 기기 기록 삭제를 사용할 수 있다. Google SDK가 보유하는 정보를 기기 기록 삭제가 함께 삭제한다고 안내하지 않는다.
