# Google Play 등록 이미지

개인 기록과 운동 수행을 한곳에서 정리하는 성인 대상 건강 기록 도구다. 기존 민트·짙은 청록 저널 로고를 그대로 사용한다. 의료 기관, 의료기기, 임상 검증이나 치료 효과를 암시하는 요소를 넣지 않는다.

아이콘은 기존 1024px 로고를 512px로 줄인다. 1024×500 그래픽은 실제 오늘 화면과 운동 시범 화면, 앱 이름과 짧은 기록 안내를 배치한다. 스크린샷은 Android API 36의 별도 임시 에뮬레이터에서 1080×1920으로 캡처한다. 실사용자 데이터는 사용하지 않으며 예시 기록은 `Example record for store preview.`로 식별한다. 시작 화면, 운동 선택과 시범, 진료 준비 화면을 담는다. 개발 메뉴와 디버그 배지는 제외한다.

실제 화면은 개발 빌드로 캡처했다. production의 화면 캡처 방지 기능은 유지한다. 이 이미지 검수는 Play에서 설치한 출시 후보의 실기기 검증을 대신하지 않는다.
